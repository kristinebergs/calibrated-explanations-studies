# When Explanations Compete: Policy-Aware Selection Under Uncertainty

This directory holds the maintained experiment code for this article. The 2024
*Ensured: Explanations for Decreasing the Epistemic Uncertainty in Predictions*
study is archived in `legacy/ensure` as historical reproduction material.

## Environment and data

Use Python 3.11 and the direct dependencies pinned in `environment.yml`.
The integration smoke checks were performed with Python 3.14.2,
`calibrated-explanations` 0.11.3.dev0, NumPy 2.3.5, pandas 3.0.0,
scikit-learn 1.8.0, and crepes 0.9.0. This is a development build, so these
checks do not establish byte-for-byte reproduction in the pinned environment.
The 2024 study pins CE 0.4.0 for its separate historical experiment.

Run from the repository root. The shared data are read locally from:

- Binary: `data/{dataset}.csv` (semicolon separated, `Y` target).
- Multiclass: `data/Multiclass/multi/{dataset}.csv` (semicolon separated, last target column).
- Regression: `data/reg/{dataset}.txt` (`REGRESSION` target), plus the two
  explicitly supported CSV datasets in `data/reg/`.

No dataset is downloaded. `datasets_ensure.py` is the registry and sole loader
for these runners. See `SOURCE_INVENTORY.md` for source provenance.

## Run

```bash
conda env create -f studies/when-explanations-compete-policy-aware-selection-under-uncertainty/environment.yml
conda activate when-explanations-compete
python studies/when-explanations-compete-policy-aware-selection-under-uncertainty/experiment_ensure_binary.py --datasets diabetes --test-size 2 --calibration-sizes 100
python studies/when-explanations-compete-policy-aware-selection-under-uncertainty/experiment_ensure_multiclass.py --datasets wineR --test-size 8 --calibration-sizes 100
python studies/when-explanations-compete-policy-aware-selection-under-uncertainty/experiment_ensure_regression.py --datasets abalone --test-size 2 --calibration-sizes 100
python studies/when-explanations-compete-policy-aware-selection-under-uncertainty/export_ensure_tables_latex.py --binary studies/when-explanations-compete-policy-aware-selection-under-uncertainty/results/results_ensure_binary.pkl --multiclass studies/when-explanations-compete-policy-aware-selection-under-uncertainty/results/results_ensure_multiclass.pkl --regression studies/when-explanations-compete-policy-aware-selection-under-uncertainty/results/results_ensure_regression.pkl
```

Omit `--datasets` for the full registry and `--test-size` for the reference
100 held-out cases. The default calibration sizes are 100, 300, and 500;
the default random seed is 42. Each explanation is evaluated as single-feature
(`explore`) and with conjunctions (`conjugate` in the result schema). The
three runners write pickle dictionaries under `results/`; the exporter writes
LaTeX under `latex_tables/`. These generated directories are ignored by Git.
Only load pickle files generated by trusted code.

Each pickle has top-level `task`, `config`, `datasets`, and `results` fields.
`results[dataset]` contains dataset metadata and blocks keyed by calibration
size and mode. Regression additionally separates `plain` from `probabilistic`
thresholds (`p25`, `p50`, `p75`), with threshold values in metadata. The mode
`conjugate` includes single-feature candidates plus conjunctions.

The article's ranking score is implemented in `common_ensure.selection_score`:
`S_w = (1-|w|)(1-U) + |w|D_w`, where `D_w=P` for nonnegative weights and
`D_w=1-P` for negative weights. Classification and thresholded regression use
probability coordinates. Plain regression uses a numeric prediction coordinate,
scaled within each candidate set along with interval width; it is not a
confidence probability. `ensured` is a candidate filter and adds no new
coverage guarantee. Eligibility precedes any optional Pareto screening.

## Current limits

The imported exporter duplicates some policy ranking blocks. The current
disagreement statistic selects the first maximizer and is not tie-aware.
The imported summaries omit case-level candidate coordinates; they cannot
support the revised Table 7, seed-level robustness, or a fair ideal-point
comparison. These issues are reserved for the reviewer-evidence step. Outputs
from this integration are implementation checks, not verified manuscript
results. The ZIP documentation's quoted empirical values have not been
verified here.
