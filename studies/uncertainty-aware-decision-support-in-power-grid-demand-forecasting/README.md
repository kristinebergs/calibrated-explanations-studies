# Uncertainty-Aware Decision Support in Power-Grid Demand Forecasting

## Reproducibility status

This paper uses operational energy-consumption data from Jönköping Energi. The underlying data cannot be redistributed because of company restrictions. A complete public reproduction package is therefore not provided.

This study intentionally contains only this README. It records the paper in the studies index and documents the reproducibility boundary without creating empty experiment or result directories.

The paper describes the model and experimental protocol, while the online-calibration functionality is maintained as part of the Calibrated Explanations development line. Reproducing the reported case study requires access to the original restricted data and associated case environment.
