# Calibrated Explanations for Within-Spec Risk Prediction: Uncertainty-Aware Decision Support

## Status of this reproduction package

This study folder preserves the code and artefacts that can currently be recovered from the paper repository. It is intentionally incomplete rather than reconstructed from assumptions.

**Raw experiment result files used for the reported benchmark tables are not currently available in the GitHub repositories inspected.** They may exist on the authors' local storage and can be added here when recovered.

The source paper repository contains the manuscript and generated evaluation figures, demonstrating that the experiments were run, but the complete raw-results pipeline is not present on its current branch.

## Available material

`paper-code/` contains source material from the paper repository that documents the implemented Within-Spec method and its experimental use. `figures/` contains the surviving generated benchmark figures.

These artefacts are preserved with provenance; they should not be interpreted as a complete one-command reproduction package until the original raw result files and any missing runner scripts are recovered.

## Missing material

- raw per-run/per-dataset result files behind the aggregate tables;
- any experiment runner scripts that were used but are no longer present in the current paper repository;
- a fully pinned historical execution environment.

If these files are recovered from local storage, they should be added without rewriting the surviving historical artefacts.

## Provenance

Recovered from `tuvelofstrom/calibrated-interval-explanations-paper`, current `main` state at migration time. The study directory is created now so that the paper has an explicit reproducibility home even while recovery is incomplete.
